# Provided frontend — Module 2

The React UI is preserved from the instructor reference. Start it with `./scripts/start-module2.sh` from the repository root. Learners edit the backend exercise file, not this frontend.

Checks from the root: `pnpm --dir module-2/frontend test`, `pnpm --dir module-2/frontend lint`, `pnpm --dir module-2/frontend build`. Browser tests remain available through `pnpm --dir module-2/frontend exec playwright test` after installing Playwright browsers. See the root guide for setup and ports.
